01 / Abstract

What this project is

This project compiles a sample list of Malayalam stop words represented in Manglish—the Roman-script spelling of Malayalam. The Python file stores the entries in a set, which keeps the collection unique, and prints the total number of unique items when run.

The resource is intended as a starting point for text preprocessing, such as filtering frequent function words before exploratory NLP analysis. It is a manually assembled sample list, not a validated or exhaustive linguistic resource.

02 / Research question

Questions guiding the work

Primary question

How can a reusable starter list of Malayalam function words in Manglish support basic text-cleaning workflows?

Practical question

What should be checked before using a Romanised stop-word list to filter real-world Malayalam text?

05 / Limitations

Use with care

Coverage is unverified

The submitted file offers sample entries but provides no corpus, frequency counts, annotation protocol, or completeness evaluation.

Romanisation varies

Manglish spelling is not standardised. The same Malayalam word may appear in multiple Roman spellings, so exact matching can miss variants.

Context matters

A word that is uninformative in one task may carry meaning in another. Removing every listed form can change sentiment, negation, or intent.

Tokenisation matters

Some entries contain spaces and inflected forms. The matching strategy should account for phrases, punctuation, and morphology.
